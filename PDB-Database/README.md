# PDB Database

This directory stores experimental protein coordinate files downloaded by the scripts in [`step-0-download-scripts/`](../step-0-download-scripts/).

> **Note**: Raw coordinate files (`.ent`, `.pdb`, `.ent.gz`) in this directory are excluded from git version control due to file size constraints.

## Directory Layout

When the download scripts are executed, structures are grouped into subdirectories by ion type:

```text
PDB-Database/
├── README.md
├── nh4_protein_only/       # Generated by download-nh4.py (Ammonium-bound structures)
│   ├── pdb1cpd.ent
│   ├── pdb1d7i.ent
│   └── ...
├── pot_protein_only/       # Generated by download-pot.py (Potassium-bound structures)
│   ├── pdb2act.ent
│   └── ...
└── sod_protein_only/       # Generated by download-sod.py (Sodium-bound structures)
    ├── pdb1a18.ent
    └── ...
```

## How to Populate

Run any of the acquisition scripts from the repository root:

```bash
# Ammonium-bound proteins
python step-0-download-scripts/download-nh4.py

# Potassium-bound proteins
python step-0-download-scripts/download-pot.py

# Sodium-bound proteins
python step-0-download-scripts/download-sod.py
```

The scripts automatically query the RCSB PDB Search API v2 for protein-only entries with non-covalently coordinated ions, fetch all matching PDB identifiers, and download them via Biopython into their corresponding folder.
